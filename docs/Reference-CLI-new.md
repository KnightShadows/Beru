# `beru new`

Scaffolds a new Beru project from scratch.

## Usage
```bash
beru new <path>
```

## Description
This command creates a new directory at the specified `<path>`, generating a standard project layout:
- A `Beru.toml` manifest file with the project name derived from the path.
- A `src/` directory containing a basic `main.cpp` entry point.
- An `include/` directory for public headers.

## Options
*None.*

## Example
```bash
beru new my_awesome_app
```
