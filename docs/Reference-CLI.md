# Reference: CLI Commands

Beru's command-line interface is designed to be intuitive and similar to Cargo.

## Core Commands

*   **[`beru new`](Reference-CLI-new.md)**: Scaffold a new C++ project.
*   **[`beru init`](Reference-CLI-init.md)**: Initialize a Beru manifest in an existing directory.
*   **[`beru build`](Reference-CLI-build.md)**: Resolve dependencies, generate toolchains, and compile the project.
*   **[`beru run`](Reference-CLI-run.md)**: Build the project and immediately execute the resulting binary.
*   **[`beru resolve`](Reference-CLI-resolve.md)**: Only perform dependency resolution and update `Beru.lock`.
*   **[`beru index update`](Reference-CLI-index-update.md)**: Pull the latest package recipes from the global index.
