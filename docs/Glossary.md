# Glossary

Precise terminology used throughout Beru's documentation.

- **Manifest (`Beru.toml`)**: The file in your project defining your code, metadata, and dependencies.
- **Recipe (`recipe.toml`)**: The file in the Index defining how to fetch and build a third-party library.
- **Index**: The Git repository containing recipes. By default, `KnightShadows/beru_index`.
- **Cache**: The global folder (`~/.beru/cache/`) where Beru stores compiled binaries of your dependencies.
- **Lockfile (`Beru.lock`)**: The auto-generated file that pins the exact versions of resolved dependencies.
